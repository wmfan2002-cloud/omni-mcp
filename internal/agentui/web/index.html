Hub 与设备身份

Agent 通过标准 HTTPS (443) 主动反向连接你的 Hub，无需开放本机端口或配置公网 IP。

无需手动填密钥：填写 Hub 地址与自定义设备名后，直接点击「连接 Hub」即可一键在 Hub 批准接入。
高级选项：手动粘贴静态令牌（可选，通常无需填写）
若 Hub 使用传统静态环境变量模式，可粘贴 OMNI_AGENT_TOKEN_MY_WORKSTATION 对应的令牌值。

启动与保存行为

加密保存配对令牌
开启后令牌仅存储在当前用户的本地受保护配置中，下次打开免重新输入。
启动程序时自动连接
双击打开客户端后立即发起连接，无需手动点击连接按钮。

授权工作目录

文件读写、搜索和补丁通过操作系统目录句柄（os.Root）强隔离，AI 无法越界访问未授权路径。

终端命令执行权限

按最小权限原则，命令执行默认关闭；仅当你信任所连 Hub 时再开启。
